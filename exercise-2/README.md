# React Exercise 2

## Topic

Component Composition & Hierarchy

## What I Practiced

* Creating multiple React components
* Practicing component composition
* Understanding component hierarchy
* Creating `Blog`, `Post`, and `Footer` components
* Using multiple components inside the `App` component
* Understanding parent and child components

## Components

### Blog

A component used as part of the blog UI.

### Post

A component used to display a blog post.

### Footer

A component used to display the footer section.

### App.jsx

The main parent component that imports and renders the other components.

## Technologies

* React
* JavaScript
* Vite

## Goal

The goal of this exercise is to understand **component composition and hierarchy** by creating multiple components and using them inside the `App` component.

The exercise also focuses on understanding the relationship between **parent and child components** in React.
