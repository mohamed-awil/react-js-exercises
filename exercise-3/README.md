# React Exercise 3

## Topic

React Props

## What I Practiced

* Understanding props in React
* Passing data from a parent component to a child component
* Passing `name` and `email` as props
* Passing data from `App` component to `UserCard` component
* Using props inside a child component

## Components

### App.jsx

The parent component that contains the `name` and `email` data and passes them to the `UserCard` component as props.

### UserCard.jsx

The child component that receives the `name` and `email` props and uses them to display user information.

## Technologies

* React
* JavaScript
* Vite

## Goal

The goal of this exercise is to understand how **props** are used to pass data from a parent component to a child component in React.
