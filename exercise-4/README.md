# React Exercise 4

## Topic

React useState

## What I Practiced

* Understanding `useState`
* Creating state in a React component
* Updating state with a state setter function
* Changing UI based on state
* Creating ON and OFF functionality
* Using button to change state

## Components

### App.jsx

The main component that manages the ON/OFF state and updates it when the button is clicked.

## What I Built

I created a simple ON/OFF functionality using `useState`.

The user can click the button to change the state between **ON** and **OFF**.

## Technologies

* React
* JavaScript
* Vite

## Goal

The goal of this exercise is to understand how `useState` is used to store and update changing data in a React component, and how state changes can update the UI.
