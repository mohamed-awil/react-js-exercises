# React Exercise 1

## Topic

React Components & Export Default

## What I Practiced

- Creating a React component
- Creating a `UserCard` component
- Using `export default`
- Importing a component into `App.jsx`
- Rendering `UserCard` inside `App.jsx`

## Components

### UserCard.jsx

A reusable component that displays user information.

### App.jsx

The main component that imports and renders `UserCard`.

## Technologies

- React
- JavaScript
- Vite

## Goal

The goal of this exercise is to understand how React components are created, exported, imported, and rendered together to build a UI.
